# ダークモード導入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ProofLoop全ページに手動トグル方式のダークモードを導入する。既存の6色デザイントークンをCSS変数化し、`bg-ink`等の既存クラスをそのまま使っているコードは無変更でダーク対応させる。

**Architecture:** `app/globals.css`に`:root`（ライト）と`:root.dark`（ダーク）でCSS変数（`--color-ink`等）を定義し、`tailwind.config.ts`の色定義をそのCSS変数への参照に切り替える。テーマの状態管理は新規`ThemeProvider`（React Context）が持ち、`localStorage`に永続化する。ページ読み込み時のフラッシュ防止に`next/script`の`beforeInteractive`インラインスクリプトを使う。トグルボタンは全ページ共通の`AppShell`ヘッダーに1箇所実装する。

**Tech Stack:** Next.js 15 App Router / TypeScript / Tailwind CSS / React Context / `next/script`

## Global Constraints

- 設計書：`docs/superpowers/specs/2026-08-22-dark-mode-design.md`
- 切り替え方式は**手動トグルのみ**。OSの`prefers-color-scheme`には自動追従しない
- 新しい色を追加しない。ダークモードの6色は設計書§2.3の値を**そのまま**使う（ブラウザモックアップで承認済み）：
  - paper: `#0A1420` / mist: `#111E2E` / ink: `#EDF1F7` / graphite: `#B8C2CE` / rule: `#28364A` / seal: `#C4362B`
- `borderRadius`（全キー`0px`）・書体（mincho/body/numeric）は変更しない（色のみの切り替え）
- 固定色でのホバー上書き（`hover:bg-[#001f45]`等）はすべて`hover:opacity-90`に置き換える（新しいCSS変数を増やさない）
- `tailwind.config.ts`の22個の旧エイリアス色は生のTailwindクラスとしての使用がゼロ件であることを確認済み。**削除のみでよく、移行作業は不要**
- モーダルの背景スクリム（`bg-black/40`・`bg-black/50`）は変更不要（ライト・ダーク両方で意味的に正しく機能するため対象外）
- `npm run dev`と`npm run build`を同時に走らせない

- [ ] **Step 1: `contexts/ThemeContext.tsx`を新規作成する**

```tsx
"use client";

import { createContext, useCallback, useContext, useEffect, useState } from "react";

type Theme = "light" | "dark";

const STORAGE_KEY = "proofloop-theme";

type ThemeContextValue = {
  theme: Theme;
  toggleTheme: () => void;
};

const ThemeContext = createContext<ThemeContextValue | null>(null);

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<Theme>("light");

  // 初期化スクリプト（app/layout.tsxのbeforeInteractiveスクリプト）が
  // <html>に既に正しい.darkクラスを付けているはずなので、マウント後に
  // その実際の状態へ同期する（サーバー側は常にlightでレンダリングされるため）。
  useEffect(() => {
    setTheme(document.documentElement.classList.contains("dark") ? "dark" : "light");
  }, []);

  useEffect(() => {
    document.documentElement.classList.toggle("dark", theme === "dark");
    localStorage.setItem(STORAGE_KEY, theme);
  }, [theme]);

  const toggleTheme = useCallback(() => {
    setTheme((prev) => (prev === "dark" ? "light" : "dark"));
  }, []);

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme(): ThemeContextValue {
  const ctx = useContext(ThemeContext);
  if (!ctx) {
    throw new Error("useTheme must be used within ThemeProvider");
  }
  return ctx;
}
```
