## 2. 補足：なぜこの3つなのか

| # | 依頼 | 入らないと何が起きるか | 入ると何が解けるか |
| --- | --- | --- | --- |
| ① | Rank Tracker のKW登録 | **順位の定点観測がゼロのまま。** GSCの平均掲載順位で代用はできるが、自サイトの数値しか無く**競合との相対比較ができない** | 施策の効果を「順位が何位上がったか」で言えるようになる。イシューツリー7.1の週次順位追跡 🔴 が解ける |
| ② | Site Audit のクロール設定 | **Core Web Vitals が未計測のまま**（イシューツリー3.1 🔴）。2,438URLの技術的な問題を発見できない | LCP/CLSの閾値割れ、リダイレクト・重複・noindexの誤設定を機械的に検出できる |
| ③ | オーナーへの席付与 | 設定変更のたびにCEO依頼＝**二桁日数のリードタイム**。アラート設定・GSC再認可・ユニット枠の内訳確認ができない | 設定系を自走できる。①②の再設定・KW入れ替えを都度待たずに回せる |

### ③ 席について調べた事実（2026-07-29 時点・公開情報）

**費用**

- [料金ページ（jp）](https://ahrefs.com/pricing)の表示：**Lite は1ユーザー込み・追加は最大2名まで・1名あたり ¥6,160/月**（年 ¥73,920）。
- ⚠️ 一方 [ヘルプセンター](https://help.ahrefs.com/en/articles/411099-how-do-i-add-and-manage-users-to-my-account-s-workspace)には「Lite は追加2ユーザーを含む（月500クレジット）」と読める記述もあり、**公開情報が食い違っている**。Ahrefsがクレジット制へ移行した経緯があるため、契約時期で条件が異なる可能性がある。
- **確定値は契約者の Account → Billing 画面にしか出ない**ため、依頼文で確認をお願いする形にした。

**権限スコープ — 「ProofLoopだけ見せる」は Lite では不可**

| ロール | できること |
| --- | --- |
| Member | 自分に共有されたオブジェクト＋「All workspace members」に共有されたものにアクセス。新規作成も可 |
| Admin | 全オブジェクト＋設定・課金・ユーザー管理 |
| Owner | Admin と同等。作成者に自動付与・変更不可 |
| Guest | **プロジェクト単位でアクセスを限定できる。ただし Enterprise プラン限定** |

- したがって **Lite で「ProofLoopのプロジェクトだけ」に絞ることはできない**。
- さらに `management-projects` の実測で、**9プロジェクトすべてが `access: shared`**（ワークスペース全体に共有済み）であることを確認済み。この共有設定を個別に変更しない限り、Member でも他案件が見える。
- ただし **Member は設定・課金・ユーザー管理ができない**ため、他案件を誤って壊すことは構造的にできない。依頼文ではこの点を**先に申告**した（隠して頼むより通りやすいため）。

### 補足：③が見送りになった場合の代替

Ahrefs の**データ取得はすべてAPI連携（Claude）から可能**なので、①②さえ入れば分析は回せる。加えて、**Ahrefs Webmaster Tools（AWT）は無料**で、`contact@proofloop.jp` 自身のアカウントを作り `proofloop.jp` の所有権を確認すれば以下が使える（竹中さんのワークスペースとは完全に独立）：

- Site Audit（技術SEO 170項目以上・月5,000クロールクレジット/プロジェクト ※2,438URLなら月1回のフルクロール相当）
- Site Explorer（自サイトの被リンク・流入キーワード 各1,000件まで）
- Web Analytics

**AWTに無いもの**：Keywords Explorer（Vol/KD調査）・Rank Tracker（順位追跡）・競合分析。つまり**②はAWTで代替可能だが、①は代替できない**。
⚠️ AWTのデータは**MCP（API連携）からは読めない**（MCPは竹中さん側ワークスペースのキーを参照するため）。自動レポートに載せたいなら②はCEO側での設定が必要。
