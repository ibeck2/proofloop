## 2. 補足：なぜこの3つなのか

| # | 依頼 | 入らないと何が起きるか | 入ると何が解けるか |
| --- | --- | --- | --- |
| ① | Rank Tracker のKW登録 | **順位の定点観測がゼロのまま。** GSCの平均掲載順位で代用はできるが、自サイトの数値しか無く**競合との相対比較ができない** | 施策の効果を「順位が何位上がったか」で言えるようになる。イシューツリー7.1の週次順位追跡 🔴 が解ける |
| ② | Site Audit のクロール設定 | **Core Web Vitals が未計測のまま**（イシューツリー3.1 🔴）。2,438URLの技術的な問題を発見できない | LCP/CLSの閾値割れ、リダイレクト・重複・noindexの誤設定を機械的に検出できる |
| ③ | オーナーへの席付与 | 設定変更のたびにCEO依頼＝**二桁日数のリードタイム**。アラート設定・GSC再認可・ユニット枠の内訳確認ができない | 設定系を自走できる。ただし**①②が入れば当面の実害はほぼ消える**ため優先度は低い |

### なぜ③を「急ぎでない」としたか

Ahrefs の**データ取得はすべてAPI連携（Claude）から可能**です。GSC・Keywords Explorer・SERP・被リンク・競合分析・Site Audit の結果閲覧まで、読む操作に席は要りません。席が本質的に必要なのは「設定変更」「アラート」「UIでの探索的な閲覧」に限られ、まだ順位追跡すら始まっていない現段階では投資対効果が薄いと判断しました。

### キーワードリストの根拠

- 初版28語は `docs/seo/rank-tracker-keywords.md`（2026-07 の Ahrefs 実測に基づくクラスタ設計）。
- **2026-07-29 に GPAクラスタ7語を追加**しました。理由は、`/gpa` が **GSC上で既に8キーワードの表示を獲得し、順位6〜15位に付けている** ProofLoop唯一の「検索に評価されているページ」であるにもかかわらず、初版リストに `大学 gpa 平均` しか入っていなかったためです。
  - 本命は `gpa 計算`（Vol 2,300 / KD 0）と **`大学 gpa`（Vol 1,200 / KD 3・TP 5,200）**。後者は親トピック「gpaとは」経由で `gpa 計算` の2.6倍の潜在流入があります。
  - 大学名つきロングテール（京大40・東大30・北大10）は流入源としては小さいものの、**既に上位に付けているため「東大対応が実際に評価されているか」の先行指標**として追跡します。
  - `基本平均点` は owner-todo で目玉KWとされていましたが、**Vol実測が0**だったため除外しました。
  - 実測値の詳細：`docs/seo/keyword-facts.md`（2026-07-29 エントリ・消費264ユニット）
