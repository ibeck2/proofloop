## 次にやること（インパクト×手間ランク）

### 1.【インパクト特大・手間小】団体ページの description を事実データから生成する

**根拠**：団体ページは 5〜11位に大量に付いているのに、表示10〜17でクリック0が並ぶ（上表）。順位が原因ではない。原因は**スニペットが空虚**なこと。`organizations` の説明文は 1,958件中1件しか入っておらず（`docs/task-board.md`）、description が汎用文になっている。

**やること**：`generateMetadata`（実装済み）が使う description を、保有している事実データ（大学名・カテゴリ・人数・活動場所）から機械生成する純粋関数を `lib/organizations/` に追加する。文章の創作ではなく**事実の要約**なので、早稲田収集の権利論点にも触れない。

**効き方**：472ページ×平均10表示の母数に対し、CTRが 0% → 3% になるだけでサイト全体のクリックが倍増する。**現状で最もクリック数を動かす一手。**

### 2.【インパクト大・手間中】「クロール済み - インデックス未登録」115ページを解消する

**根拠**：GSC のインデックス登録は 472 / サイトマップ2,438 URL＝**19%**。未登録116のうち115が「クロール済み - インデックス未登録」＝Googleが見た上で**載せる価値がないと判断**した状態。薄いコンテンツの典型症状で、提案1と同根。

**やること**：提案1を先に打ち、次回PDCAで115が減るかを見る。減らなければ、団体ページに構造化データ（`Organization` schema）を足す。**提案1の効果測定を兼ねるので、単独では着手しない。**

### 3.【インパクト中・手間小】`/guide/credits` の受け皿を直す

**根拠**：`大学 選択科目 落とす gpa` で **6.0位・表示17・クリック0**、かつGA4の平均滞在が **9秒**（全ページ中最短）。上位表示されているのにクリックも滞在もされない＝**クエリ意図と中身がずれている**。ユーザーは「単位を落としたらGPAはどうなるか」を知りたいが、ページはそれに正面から答えていない可能性が高い。

**やること**：「落とした単位・不可はGPAにどう影響するか」に直接答えるH2とFAQを追加し、`/gpa` へ内部リンクを通す。既存の `lib/gpa/failExclusion.ts`（不可を分母に含めるかの切替）がそのまま説明材料になる。

### 4.【インパクト中・手間小】GA4の海外ボットを除外する

**根拠**：28日のアクティブユーザー299人の内訳は Japan 139・**Singapore 88（エンゲージのあったセッション0・滞在0秒）**・(not set) 31・US 12・Netherlands 11・Poland 5・Belgium 4・Iran 3。**Japan以外の160人（53%）は滞在0秒**で、実ユーザーではない。前回提案2の積み残し。

**✅ 実施済み（2026-08-06・Claude）**：保存済みの比較 **「日本のみ（海外ボット除外）」**（国 完全一致 `Japan`）を作成した。以後、GA4 はこの比較を適用して読む。`seo-pdca` スキルにも手順として明記済み。

> ⚠️ **訂正**：当初「GA4のデータフィルタで日本以外を除外する」と書いたが、**これは不可能**だった。GA4 のデータフィルタで選べる種類は**デベロッパー トラフィック／内部トラフィック／ウェブホスト名のトラフィックの3つのみ**で、国による除外は存在しない（2026-08-06 に作成画面で確認）。したがって**収集時には落とせず、閲覧時に比較で除外する**のが唯一の手段。過去データも遡って正しく読める点はむしろ利点。

### 5.【インパクト中・手間小】キーイベントが0のままの原因を切り分ける

**根拠**：28日で `gpa_calculate` 2回・`affiliate_click` 3回が発火しているのに、**キーイベント合計は 0.00**（トラフィック獲得・ユーザー属性・ページ別の全レポートで一致）。両イベントは 07-25 にキーイベント化した記録がある（`docs/owner-todo.md`）。

**ただし断定はできない**：キーイベントはマークした時点以降しか集計されず、この5回の発火はいずれも 07-22・07-25 の動作確認由来の可能性がある。**次回、07-25以降の新規発火があるのにキーイベントが0のままなら、設定不備が確定する。** 今回は「要確認」に留める。

### 6.【インパクト小・手間小】`/for-students`（404）に表示6件

**根拠**：本番で404のページにGA4表示が6件・4ユーザー。フッターからは削除済みのはずなので、どこかに導線が残っているか、外部リンク／ブックマーク経由。ページを作るかの判断は `docs/owner-todo.md` に未決で残っている。

### 7.【インパクト大・手間大】一人暮らしクラスタは依然として未着手

**根拠**：`大学生 一人暮らし 初期費用` が **50位**（表示6）。Rank Tracker リストの主戦場（`大学生 一人暮らし 費用` Vol 3,300 など）に対し `/guide/living-alone` は圏外のまま。一方でGA4の平均滞在は **1分46秒**とサイト最高で、**ページの質は問題ではない**。効かないのは被リンク（DR=0）と情報量。

**判断**：DR=0の現状で Vol 3,000級は取れない。**提案1〜3を先に打ち、団体ページで積んだドメイン評価が出てから着手するのが順序として正しい。** 次回PDCAで再評価する。
